# Замер скорости интернета

Python 3.8+, без зависимостей. Скачайте `speedtest.py` и запустите:

```bash
python3 speedtest.py "https://example.com/large-image.jpg"
```

Замените URL прямой ссылкой на большой файл. Скрипт скачает его 10 раз подряд и выведет среднее время, общий объём и скорость: сумма байт / сумма времени, в Мбит/с и МБ/с (1 МБ = 1 000 000 байт).

Время включает соединение и полное скачивание; результат зависит от выбранного сервера. Таймаут сетевой операции — 30 с. При ошибках расчёт только по успешным скачиваниям, код выхода — 1.

## Файлы для проверки

Прямые ссылки OVH: [10 МиБ](https://proof.ovh.net/files/10Mb.dat) и [100 МиБ](https://proof.ovh.net/files/100Mb.dat).

```bash
python3 speedtest.py "https://proof.ovh.net/files/10Mb.dat"
python3 speedtest.py "https://proof.ovh.net/files/100Mb.dat"
```

Каждая команда скачивает файл 10 раз: 100 МиБ или 1000 МиБ трафика соответственно (1 МиБ = 1 048 576 байт).
